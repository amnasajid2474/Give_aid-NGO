# Give-AID NGO Website — Planning Pack

This pack contains the project roadmap and individual task files for building Give-AID as a solo full-stack project using ASP.NET Core MVC, C#, Entity Framework Core and SQL Server.

## Start here
1. Read `plan.md` fully.
2. Open `tasks/TASK-00-README.md` for the ordered task index.
3. Complete `TASK-01` first and proceed in dependency order.
4. Update task status, test results and blocker notes as you work.

## Important
- This pack is a plan, not the finished application code.
- Use a simulated donation/payment flow only. Never store real card details.
- The supplied eProject specification is older; the plan follows its functional requirements using the modern stack selected for this project.
