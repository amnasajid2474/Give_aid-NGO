# TASK-12 — Help Centre, Contact and queries

**Status:** Not Started  
**Dependencies:** Tasks 06 and 07  
**Estimated effort:** Estimate after checking your pace; do not treat this as a deadline.

## Objective

Let visitors submit questions and let the admin review and answer them.

## Steps

1. [ ] Build Help Centre/FAQ and Contact Us pages.
2. [ ] Create a ContactQuery model with message, contact details, created date, status and optional user relationship.
3. [ ] Validate and save submitted queries to SQL Server.
4. [ ] Build an admin-only query list/detail screen and reply/status workflow.
5. [ ] Encode output safely and validate length/required fields.
6. [ ] If email replies are implemented, use the shared email service and configuration; never expose credentials.

## Acceptance criteria

- [ ] Valid queries persist and appear in admin.
- [ ] Invalid submissions are rejected with clear messages.
- [ ] Only authorized admin users can read/manage all queries.

## Expected outputs

- `ContactQuery model and views`
- `Migration`
- `Help Centre/FAQ view`
