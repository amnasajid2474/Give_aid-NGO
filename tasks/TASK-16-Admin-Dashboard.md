**Status:** Not Started

## Objective

Create one consistent, protected dashboard that links to all admin modules.

## Steps

1. [ ] Create the admin landing page and shared sidebar/navigation.
2. [ ] Add summary counts only for data that exists and can be queried reliably.

- [ ] Admin can navigate to every implemented management area.
- [ ] Regular users cannot access the dashboard or admin actions.
- [ ] Summary numbers match database records.
