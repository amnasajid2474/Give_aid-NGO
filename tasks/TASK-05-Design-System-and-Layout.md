## Objective

Create a consistent, accessible visual shell that all pages can reuse.

## Steps

1. [ ] Choose a restrained charity/NGO visual style, color palette, type scale, spacing and button styles.
2. [ ] Update the shared Razor layout with site name/logo placeholder, navigation, main content area and footer.
3. [ ] Include navigation for Home, Donate, Help Centre, About Us, Our Partners, Programmes, Gallery, Contact and Register/Login as appropriate.

5. [ ] Add responsive CSS for desktop, tablet and mobile widths.

7. [ ] Use placeholder/sample content only; avoid spending time on final copy before functionality is stable.

## Acceptance criteria

- [ ] Layout works at mobile and desktop widths without horizontal overflow.
